## 第一层：教学内容观

### 核心理念：语文教学的本质是精神成长

王崧舟认为，语文课不仅是学习语言文字的技能课，更是**人的精神觉醒与成长的过程**。语文教学应当让学生在语言文字中"走一个来回"——从语言走向精神，再从精神回到语言。

**"诗意语文"的三层内涵**：

1. **语言之美**：语文课的第一要务是让学生感受和沉浸在母语的美感之中。汉字有形、有音、有义、有情，教师要带着学生去触摸这种美。
2. **情感之真**：每篇文章背后都站着一个人，都有一颗跳动的心。教学要帮助学生穿过文字的表层，触碰到那颗心。
3. **生命之厚**：语文课最终指向的是人的精神世界的丰盈。读一篇好文章，学生应该觉得自己"不一样了"——视野更开阔了、心灵更敏锐了、生命更丰厚了。

**关于"教什么"的观点**：语文课不是教"课文内容"，而是教"语言形式"。学生通过这篇课文，不是要记住故事情节，而是要学会这种表达方式——作者是怎样用语言来表达情感的？这种表达为什么有效？

## 第二层：教学策略库

### 策略一：反复诵读（层层递进式朗读）

**这是王崧舟最标志性的教学策略**。他不是简单地让学生"再读一遍"，而是每一次朗读都有明确的目标和新的理解层次。

**操作步骤**：

1. **第一层：读通——扫除障碍**。学生自由读，读准字音、读通句子。教师巡视，发现共性问题后集中纠正。
2. **第二层：读懂——理解内容**。带着问题读：这段话写了什么？教师提供理解支架（如关键词提示、背景知识补充）。读完后简要交流。
3. **第三层：读透——品味语言**。聚焦核心词句，反复玩味。教师引导学生关注"怎么写的"而不只是"写了什么"。这一层是课堂的核心环节，要舍得花时间。
4. **第四层：读化——融情于声**。在深度理解之后，让学生把自己的全部理解和情感注入朗读。此时的朗读不是"念课文"，而是"用心说话"。
5. **第五层：读出自我——与文本对话**。最高层次——学生能从文本中读出自己的理解、自己的生命体验。

**具体操作技巧**：
- **铺垫式导读**：在学生读之前，教师用一段深情的语言做铺垫，将学生带入情境，再让学生接着读。例如："纳兰性德离家已经整整一年了，在风雪交加的夜晚，他思念着故园的一切——读！"
- **渐次叠加**：同一段文字，每读一遍加入一层新的理解。"第一遍，你读出了思乡；第二遍，读出了孤独；第三遍，读出了无奈——来，再读一遍，这一次，把这三层感情都融进去。"
- **对比朗读**：教师故意用平淡的语气读一遍，再用深情的语气读一遍，让学生感受差异。"你们听出什么不同了？"

**经典课堂语言**：
- "读——读出你的理解。"（简洁有力的指令）
- "孩子们，你们读出了文字，但还没读出文字背后的东西。再来一次。"
- "这首词，纳兰性德在塞外的风雪中写下。他的笔是冷的，他的心是冷的，但他笔下的故园是暖的。带着这份暖，再读——'故园无此声'。"
- "山一程，水一程——你觉得这个'一程又一程'是什么感觉？路很远？走得很累？舍不得？好，带着你的感觉，读。"

### 策略二：想象补白（在文字空白处展开想象）

**操作步骤**：

1. **找到留白处**：在文本中找到作者"没有写出来"的部分。常见留白类型：省略号处、动作之间的心理活动、场景中的感官细节、时间跳跃中的空白。
2. **设计想象支架**：不是泛泛地说"你想象一下"，而是给学生一个具体的想象方向和语言支架。例如："母亲站在门口，她的眼睛看着_____，她的嘴唇_____，她的手_____。"
3. **引导学生表达**：让学生用口头或书面方式将想象的内容表达出来。教师追问、丰富、提升。
4. **回扣原文**：将学生的想象与原文对照，帮助学生理解作者为什么选择"不写"——留白本身就是一种表达策略。

**经典课堂语言**：
- "作者写到这里，用了一个省略号。同学们，这六个点里藏着什么？闭上眼睛，你看到了什么？"
- "梁晓声写'母亲掏出一卷揉得皱皱的毛票'——同学们，想一想，这些钱母亲是怎么攒下来的？一角一角，从哪里省下来的？"
- "课文里说'我的眼前一片模糊'——在模糊之中，他看到了什么？或者说，他想到了什么？"

### 策略三：情境创设（让语言在情境中活起来）

**操作步骤**：

1. **语言情境**：教师用诗意的、有画面感的语言来描述场景，将学生"带入"文本世界。这是王崧舟最拿手的技巧——他的课堂导语本身就是一篇美文。
2. **音乐情境**：在朗读或想象环节，配上与文本情感匹配的背景音乐。音乐要轻、要衬托而非抢戏。古诗词课常用古琴、箫等乐器。
3. **画面情境**：适时出示与文本内容相关的画面（水墨画、摄影、视频片段），帮助学生建立视觉表象。
4. **角色情境**：让学生进入角色——"假如你就是纳兰性德""假如你就是那个在工厂里工作的母亲"，从角色的视角去感受和表达。

**经典课堂语言**：
- "现在，你就是纳兰性德。你离开了京城，离开了你的妻子、你的父亲、你温暖的书房。你跟随大军，翻过了一座又一座山，淌过了一条又一条河。今夜，你停在了北方的荒原上。帐篷外面，风雪呼啸。你提起了笔——"
- "就在这间小小的工厂里，空气中弥漫着灰尘，机器声震耳欲聋，光线暗到你看不清母亲的脸——就在这样的环境里，母亲工作了一天又一天。"

### 策略四：板书美学（板书即思维地图）

**操作步骤**：

1. **整体设计**：板书不是随意的板书，而是课前精心设计的。要做到"一课一板书"，板书本身就是这节课的思维框架和情感脉络。
2. **逐步呈现**：板书不是一次性写完，而是随着教学推进逐步呈现。每添加一个关键词，都是一个教学节点。
3. **形式匹配内容**：板书的排列方式要与文本结构和情感走向相匹配。例如教《长相思》时，"身"在左（远行）、"心"在右（故园），中间是那个"碎"字。
4. **课末回看**：课堂结尾，引导学生回看整个板书，梳理学习过程，感受课堂的"完整"。

**经典课堂语言**：
- "（指着板书）看，我们这节课走了一条什么样的路？从'身'到'心'，从'行'到'停'，但无论走多远，心里装着的，始终是——故园。"

## 经典课例索引

### 《长相思》——诗意语文的巅峰之作

- **主题**：身与心的分离，行与思的交织
- **策略组合**：层层递进式朗读 + 想象补白 + 情境创设 + 板书美学
- **教学亮点**：
  - 全课以"读"为主线，同一首词学生读了不下十遍，但每一遍都有新的理解层次。
  - 将"身在征途"与"心系故园"作为两条线索交织推进——身向前走，心往回飞。
  - 想象补白环节："在纳兰性德的心中，故园是什么样的？是什么画面让他在风雪之夜写下这首词？"学生写出自己想象的"故园"画面，然后朗读。
  - 板书最终呈现：左边"山一程 水一程"（身），右边"风一更 雪一更"（心），中间一个大大的"碎"字——"聒碎乡心梦不成"。
- **经典语言**："山一程，水一程，程程都是——（生：远离故园）。风一更，雪一更，更更都在——（生：诉说思念）。""在纳兰性德的心中，在他的记忆里，在故园，没有风雪，没有寒冷。有的是什么？你来说。"

### 《慈母情深》——从语言形式中读出母爱的沉重

- **主题**：贫穷中的母爱——在极端环境中的人性光辉
- **策略组合**：反复诵读 + 想象补白 + 聚焦语言形式
- **教学亮点**：
  - 紧扣三个"我的母亲"的反复句式，引导学生发现：梁晓声为什么要一遍遍写"我的母亲"？这不是啰嗦，是每一次看到母亲的不同侧面时内心的震动。
  - 抓住"掏出""塞""立刻"等动词，让学生体会母亲毫不犹豫的坚定——那不是随便给一块钱，那是把自己的血汗钱塞给儿子。
  - 想象补白："工厂里的噪音、灰尘、高温，母亲弓着背在缝纫机前——你们想象一下，她在想什么？"
- **经典语言**："'背直起来了，我的母亲。转过身来了，我的母亲。褐色的口罩上方，一对眼神疲惫的眼睛吃惊地望着我，我的母亲。'——三次'我的母亲'，每一次你看到了什么？第一次看到的是——背；第二次看到的是——脸；第三次看到的是——眼睛。背是弯的，脸是黑的，眼睛是疲惫的。这就是我的母亲。"

### 《枫桥夜泊》——一首诗的文化解读

- **主题**：千年愁绪与文化传承
- **策略组合**：文化情境创设 + 层层递进式朗读 + 跨时空对话
- **教学亮点**：
  - 不止于教"一首诗"，而是教"一首诗的文化生命"——从张继写这首诗开始，到历代文人的和诗，到寒山寺的钟声成为文化符号，让学生感受"一首诗怎样活了一千多年"。
  - 核心问题："张继的'愁'是什么愁？是考试落榜的愁？是远离家乡的愁？是前途未卜的愁？还是在这个静夜里对人生的愁？"
  - 引入其他诗人关于"枫桥"和"寒山寺"的诗句，让学生发现：张继之后，无数人来到枫桥，来到寒山寺，他们在寻找什么？
- **经典语言**："从张继之后，一千多年了，一代又一代的诗人来到枫桥，来到寒山寺。他们在找什么？他们在找张继的那个夜晚，找那份愁，找那声钟。一首诗，让一座桥、一座寺、一口钟，活了一千多年。"
