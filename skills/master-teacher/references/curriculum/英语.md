# 英语课程标准（2022版）知识库
**数据来源**：2022版《义务教育英语课程标准》

---

## 一、课程性质

英语课程是义务教育阶段的必修课程，具有基础性、实践性和综合性的特点。学习和运用英语有助于学生了解不同文化，比较文化异同，汲取文化精华，逐步形成跨文化沟通与交流的意识和能力。英语课程承担着培养学生基本英语素养和发展学生思维能力的任务。

---

## 二、核心素养

英语课程要培养的学生核心素养由语言能力、文化意识、思维品质和学习能力四个方面组成，四个方面相互渗透、融合互动、协同发展。

### 1. 语言能力
- 指在社会情境中，以听、说、读、看、写等方式理解和表达意义的能力
- 包括：在具体语境中整合性地运用已有语言知识，理解口头和书面语篇所传递的意义
- 围绕特定的主题，运用口语和书面语进行有效沟通和交流
- 通过语言建构与运用，发展语言意识和语感

### 2. 文化意识
- 指对中外文化的理解和对优秀文化的鉴赏
- 学生在全球化背景下表现出的知识素养、人文修养和行为取向
- 包括：了解不同国家的文化，比较中外文化的异同
- 具有一定的跨文化沟通和传播中华文化的能力
- 坚定文化自信，形成自尊、自信、自强的良好品格

### 3. 思维品质
- 指人的思维个性特征，反映学生在理解、分析、比较、推断、批判、评价、创造等方面的层次和水平
- 包括：观察与辨析、归纳与推断、批判与创新
- 能辨析语言和文化中的具体现象，梳理、概括信息
- 建构新概念，分析和解决问题
- 能从多角度观察和认识世界，对事物作出正确的价值判断

### 4. 学习能力
- 指学生积极运用和主动调适英语学习策略、拓宽英语学习渠道、努力提升英语学习效率的意识和能力
- 包括：能够根据需要制订学习计划
- 多渠道获取英语学习资源
- 选择恰当的策略与方法，监控、评价、反思和调整自己的学习
- 做到乐学善学

---

## 三、课程目标

### 总目标
学生通过英语课程的学习，达到以下目标：
1. 发展语言能力，能够在日常生活和学习中用英语进行有效沟通
2. 培育文化意识，加深对中华文化的理解和认同，拓展国际视野
3. 提升思维品质，能够用英语进行多元思维活动
4. 提高学习能力，养成自主学习和终身学习的意识和习惯

### 分级目标
义务教育英语课程设置三级目标体系：

| 级别 | 对应年级 | 定位 |
|------|---------|------|
| 一级 | 3-4年级 | 学习理解（感知与体验） |
| 二级 | 5-6年级 | 应用实践（习得与内化） |
| 三级 | 7-9年级 | 迁移创新（整合与运用） |

## 四、课程内容

### 2022版课标的核心创新：英语课程内容六要素

英语课程内容由**主题、语篇、语言知识、文化知识、语言技能、学习策略**六个要素组成。六要素构成一个相互关联的有机整体。

---

### 要素一：主题

主题为语言学习和课程育人提供语境范围，涵盖三大主题范畴：

| 主题范畴 | 主题群 | 子主题举例 |
|---------|--------|-----------|
| **人与自我** | 生活与学习 | 日常生活、饮食健康、学校生活、个人兴趣爱好 |
| | 做人与做事 | 良好品行、劳动习惯、自我认识、生活态度 |
| **人与社会** | 社会服务与人际沟通 | 家庭生活、学校生活、社区服务、人际交往 |
| | 文学、艺术与体育 | 文学故事、影视表演、音乐绘画、体育运动 |
| | 历史、社会与文化 | 中外节日、文化习俗、历史事件、社会变迁 |
| | 科学与技术 | 科学探索、发明创造、信息技术、未来生活 |
| **人与自然** | 自然生态与环保 | 自然景观、天气季节、动植物世界、环境保护 |
| | 宇宙探索 | 地球与太空、天文现象 |

#### 各学段主题侧重
- **一级（3-4年级）**：围绕"人与自我"和"人与社会"中贴近学生日常生活的主题（如家庭、学校、朋友、动物等）
- **二级（5-6年级）**：拓展至"人与自然"，主题更加丰富多样（如节日文化、社区服务、自然环境等）
- **三级（7-9年级）**：主题范围进一步扩大（如历史文化、科技创新、全球议题、个人成长等）

---

### 要素二：语篇

语篇为语言学习提供文体素材和真实语境。

| 语篇类型 | 具体形式 |
|---------|---------|
| 连续性文本 | 记叙文、说明文、应用文、议论文 |
| 非连续性文本 | 图表、图示、广告、网页、表格 |
| 口头语篇 | 对话、讨论、独白、演讲 |
| 多模态语篇 | 视频、歌曲、海报、动画 |

#### 各学段语篇要求
- **一级（3-4年级）**：简单的对话、韵文、歌谣、小故事；配图故事
- **二级（5-6年级）**：简短的书信、电子邮件、简单的说明文；连环画、海报
- **三级（7-9年级）**：篇章结构较为完整的记叙文、说明文、议论文；新闻报道、人物传记、科技短文

---

### 要素三：语言知识

语言知识包括语音、词汇、语法、语篇和语用知识。

#### 语音知识
| 学段 | 要求 |
|------|------|
| 一级（3-4年级） | 了解26个字母的读音和书写；感知英语的语音语调特点；能在教师指导下跟读课文 |
| 二级（5-6年级） | 了解单词有重音；了解语句有重音；了解英语语音语调在表意功能上的作用 |
| 三级（7-9年级） | 了解英语的重音、语调、连读、节奏等语音现象；能在口语表达中做到语音、语调基本正确 |

#### 词汇知识
| 学段 | 词汇量要求 |
|------|-----------|
| 一级（3-4年级） | 学习并积累约450个单词 |
| 二级（5-6年级） | 累计学习约700个单词 |
| 三级（7-9年级） | 累计学习约1600个单词，同时学习约200个习惯用语或固定搭配 |

#### 语法知识
| 学段 | 主要语法项目 |
|------|-------------|
| 一级（3-4年级） | 名词单复数；常用人称代词和形容词性物主代词；be动词和常用行为动词的一般现在时；简单的陈述句和疑问句 |
| 二级（5-6年级） | 一般过去时（规则和不规则动词）；现在进行时；there be结构；形容词比较级和最高级；基数词和序数词 |
| 三级（7-9年级） | 八种基本时态（一般现在、过去、将来，现在/过去进行，现在/过去完成，过去将来）；被动语态；宾语从句、状语从句、定语从句（限制性）；不定式和动名词 |

#### 语篇知识
- 了解语篇的基本结构和逻辑关系
- 一级：对话和短文的基本结构
- 二级：语篇中的衔接和连贯手段（如and, but, so, because等）
- 三级：理解语篇的主旨大意、段落间的逻辑关系、作者的写作意图

#### 语用知识
- 了解英语在不同社交场合中的使用规范
- 学习如何恰当地使用问候、感谢、道歉、请求、邀请等日常用语
- 了解语言使用中的礼貌原则和文化差异

---

### 要素四：文化知识

| 维度 | 内容 |
|------|------|
| 中外文化知识 | 中外重要节日和习俗；中外饮食文化；中外学校教育异同 |
| 中华优秀传统文化 | 传统节日（春节、中秋节等）；经典故事；传统艺术和手工艺 |
| 跨文化比较 | 中外日常生活方式的异同；中外社交礼仪的差异 |
| 文化自信与传播 | 能用英语简单介绍中华文化；具有传播中华文化的意识 |

#### 各学段文化知识要求
- **一级（3-4年级）**：了解英语国家中最常见的饮食和节日文化；能用英语表达中国的重要节日
- **二级（5-6年级）**：了解中外日常生活中的文化差异；能用英语简单介绍中国的文化特色
- **三级（7-9年级）**：了解中外文化的异同，尊重文化多样性；能在语言运用中体现文化意识，具有一定的跨文化沟通能力

---

### 要素五：语言技能

语言技能包括**听、说、读、看、写**五项技能。其中，"看"（viewing）是2022版课标新增的技能维度。

#### 听
| 学段 | 要求 |
|------|------|
| 一级 | 能听懂简单的课堂用语；能听懂简短的对话和指令并做出反应 |
| 二级 | 能听懂简短的故事和对话，获取关键信息；能借助图片、关键词等辅助手段理解所听内容 |
| 三级 | 能听懂接近正常语速的故事和对话，理解主旨大意和细节信息；能根据重读和语调变化理解说话者的意图 |

#### 说
| 学段 | 要求 |
|------|------|
| 一级 | 能在教师引导下用简单的英语进行日常交流；能唱简单的英语歌曲和歌谣 |
| 二级 | 能用简短的语句描述身边的事物；能在教师指导下进行简单的角色扮演 |
| 三级 | 能就日常话题进行简短的交流；能有条理地描述个人经历和身边的事物；能在口语表达中使用恰当的语调和节奏 |

#### 读
| 学段 | 要求 |
|------|------|
| 一级 | 能读懂简单的配图故事和短文；能正确朗读课文 |
| 二级 | 能读懂简短的书信和故事等；能理解简单语篇中的主要信息；课外阅读量累计达到4000词以上 |
| 三级 | 能读懂简单的书刊和报纸上适合初中生的文章；能根据上下文和构词法推断生词含义；能找出文章中的主题句；课外阅读量累计达到15万词以上 |

#### 看（Viewing）—— 2022版新增
| 学段 | 要求 |
|------|------|
| 一级 | 能看懂简单的配图和动画中的关键信息 |
| 二级 | 能从简单的图表、海报中提取信息；能理解简单视频中的基本内容 |
| 三级 | 能从多模态语篇中获取和加工信息；能看懂英文简单视频、图表、网页等 |

#### 写
| 学段 | 要求 |
|------|------|
| 一级 | 能正确书写26个字母的大小写；能抄写简单的单词和句子 |
| 二级 | 能写简单的问候语和便条；能用简短的语句描述图片内容 |
| 三级 | 能围绕主题写出结构完整的短文（80词左右）；能使用恰当的连接词使行文连贯；能写简单的日记、书信等 |

---

### 要素六：学习策略

| 策略类型 | 内容 |
|---------|------|
| **元认知策略** | 制订学习计划；监控学习过程；评价和反思学习效果 |
| **认知策略** | 利用图片、关键词等辅助理解和记忆；利用上下文猜测词义；归纳总结语言规律 |
| **交际策略** | 运用手势、表情等辅助交流；在交流中寻求帮助；运用合适的策略克服交际困难 |
| **情感策略** | 克服学习中的焦虑情绪；保持学习英语的兴趣和积极性；乐于参与英语学习活动 |

#### 各学段策略侧重
- **一级（3-4年级）**：培养学习兴趣和良好习惯；学会借助图片和动作理解简单的英语
- **二级（5-6年级）**：初步形成自主学习意识；学会运用简单的学习策略（如预习、复习、查字典）
- **三级（7-9年级）**：能制订学习计划并监控学习进展；能选择恰当的策略解决学习中的困难；能利用多种渠道拓展学习资源

## 五、教学建议

### 总体教学建议

1. **坚持育人为本**
   - 围绕核心素养确定教学目标
   - 将立德树人根本任务融入英语教学全过程
   - 注重在主题意义探究中培养学生的语言能力和文化意识

2. **践行学思结合**
   - 引导学生在学习理解、应用实践和迁移创新等活动中习得语言知识
   - 在语言学习中发展思维品质
   - 鼓励学生独立思考、合作探究

3. **推进用创为本**
   - 在真实或模拟真实的语境中运用所学语言
   - 设计贴近学生生活的学习活动
   - 让学生在用中学、学中用

4. **秉持学用一体**
   - 以主题为引领，以语篇为依托
   - 整合性地设计教学活动
   - 促进核心素养在教学活动中的融合发展

### 各学段教学建议

#### 一级（3-4年级）教学建议
- 注重激发学习兴趣，培养良好的学习习惯
- 以听说为主，读写跟上
- 多运用歌曲、歌谣、游戏、表演等活动形式
- 创设语境，提供充分的语言输入
- 注重语音的感知和模仿，不宜过早要求拼写

#### 二级（5-6年级）教学建议
- 在巩固听说的基础上，加强读写训练
- 注重语篇教学，引导学生获取和加工语篇信息
- 培养学生初步的自主学习能力
- 开始有意识地进行语音知识的学习
- 引导学生积累词汇和常用表达

#### 三级（7-9年级）教学建议
- 注重发展学生的综合语言运用能力
- 深化语篇分析和解读，培养学生的思维品质
- 加强阅读教学，扩大阅读量
- 写作教学要从模仿到自主表达
- 注重语法的意义和功能，避免单纯的语法讲授
- 引导学生关注文化差异，培养跨文化意识

### 教学评价建议

1. **坚持教-学-评一体化**
   - 以核心素养为导向设计评价标准
   - 将评价贯穿教学全过程
   - 发挥评价的诊断和激励功能

2. **注重形成性评价与终结性评价相结合**
   - 日常观察、课堂表现、作业完成等形成性评价
   - 阶段测试、期末考试等终结性评价
   - 注重评价方式的多元化

3. **关注学生的学习过程**
   - 关注学生在学习过程中的情感态度
   - 评价学生运用英语解决实际问题的能力
   - 鼓励学生自评和互评

## 六、课标金句（常用引述）

> "英语课程要培养的学生核心素养包括语言能力、文化意识、思维品质和学习能力，四个方面相互渗透、融合互动、协同发展。"

> "秉持在体验中学习、在实践中运用、在迁移中创新的学习理念，倡导学生围绕真实情境和真实问题，激活已知，参与到指向主题意义探究的学习理解、应用实践和迁移创新等一系列相互关联、循环递进的语言学习和运用活动中。"

> "英语课程内容由主题、语篇、语言知识、文化知识、语言技能和学习策略等要素构成。围绕这些要素，通过学习理解、应用实践、迁移创新等活动，推动学生核心素养在义务教育全程中持续发展。"

> "教学设计与实施要以主题为引领，以语篇为依托，通过学习理解、应用实践和迁移创新等层层递进的语言和思维活动，引导学生整合性地学习语言知识和文化知识。"

> "教师要善于提出从理解到应用、从分析到评价等有层次的问题，引导学生的思维从低阶向高阶稳步发展。"

> "注重'教-学-评'一体化设计。教师应准确把握教、学、评在育人过程中的不同功能，树立'教-学-评'的整体育人观念。"

> "文化意识的培育有助于学生增强家国情怀和人类命运共同体意识，涵养品格，提升文明素养和社会责任感。"

> "语言能力是核心素养的基础要素，文化意识体现核心素养的价值取向，思维品质反映核心素养的心智特征，学习能力是核心素养发展的关键要素。"

## 七、附录参考

### 义务教育英语课程词汇表概况
- 一级（3-4年级）：约450个单词，以日常生活高频词为主
- 二级（5-6年级）：累计约700个单词，增加描述性和功能性词汇
- 三级（7-9年级）：累计约1600个单词 + 约200个习惯用语或固定搭配

### 语法项目分级表概况

```
一级（3-4年级）
├── 名词：可数/不可数，单复数
├── 代词：人称代词（主格），形容词性物主代词
├── 动词：be动词，常用行为动词一般现在时
├── 句型：简单陈述句，一般疑问句，特殊疑问句（what, who, where, how）
└── 其他：冠词a/an/the的基本用法

二级（5-6年级）
├── 时态：一般过去时，现在进行时，一般将来时（be going to）
├── 名词：名词所有格
├── 形容词：比较级和最高级
├── 句型：there be结构，祈使句
└── 其他：介词短语，基数词和序数词

三级（7-9年级）
```
