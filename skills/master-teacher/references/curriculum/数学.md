# 数学课程标准（2022版）知识库
**数据来源**：2022版《义务教育数学课程标准》

---

## 一、课程性质

数学是研究数量关系和空间形式的科学。数学源于对现实世界的抽象，基于抽象结构，通过符号运算、形式推理、模型构建等，理解和表达现实世界中事物的本质、关系和规律。数学课程具有基础性、普及性和发展性，是培养公民素质的基础课程。

---

## 二、核心素养

### 总体描述："三会"
数学课程要培养的学生核心素养，主要表现为以下三个方面：
1. **会用数学的眼光观察现实世界**
2. **会用数学的思维思考现实世界**
3. **会用数学的语言表达现实世界**

"三会"是数学课程核心素养的集中体现，是在数学学习和应用的过程中逐步形成和发展的。

### 核心素养的主要表现（11个关键词）

#### 小学阶段表现
| 核心素养 | 含义 |
|---------|------|
| **数感** | 对数与数量、数量关系及运算结果的直观感悟；能在真实情境中理解数的意义，能用数表示物体的个数或事物的顺序 |
| **量感** | 对事物的可测量属性及大小关系的直观感知；能够合理得到或估计度量的结果 |
| **符号意识** | 能够感悟符号的数学功能，知道用符号表示数、数量关系和变化规律；能够初步运用符号进行运算或推理 |
| **运算能力** | 根据法则和运算律正确进行运算的能力；能够理解运算的算理，寻求合理简洁的运算途径解决问题 |
| **几何直观** | 利用图形描述和分析问题的意识和习惯；借助图形理解和解决有关数学问题 |
| **空间观念** | 根据物体特征抽象出几何图形，根据几何图形想象出所描述的实际物体；想象出物体的方位和它们的相互位置关系 |
| **推理意识** | 对获得数学猜想和数学结论的过程的感悟；了解推理是获得数学结论、构建数学体系的重要方式 |
| **数据意识** | 对数据的意义和随机性的感悟；知道在现实生活中，有许多问题应当先做调查研究，收集数据 |
| **模型意识** | 对运用数学模型解决实际问题的自觉意识；知道数学模型可以用来解决一些实际问题 |
| **应用意识** | 主动尝试从数学的角度运用所学知识和方法解决问题的意识；认识到数学与现实世界的联系 |
| **创新意识** | 主动尝试从日常生活、自然现象或科学情境中发现和提出有意义的数学问题的意识 |

#### 初中阶段表现
在小学阶段基础上进一步发展，部分素养升级：
- 数感 → **数感**（更加深化，涉及有理数、实数）
- 符号意识 → **符号意识**（发展为代数推理的基础）
- 推理意识 → **推理能力**（从"意识"发展到"能力"，包含演绎推理）
- 数据意识 → **数据观念**（从"意识"发展到"观念"，涉及统计推断）
- 模型意识 → **模型观念**（从"意识"发展到"观念"，建立数学模型解决问题）
- 几何直观 → **几何直观**（进一步发展，结合坐标方法）
- 空间观念 → **空间观念**（发展空间想象力）
- 新增：**抽象能力**（从具体到一般的数学抽象过程）

## 三、课程内容

### 主题一：数与代数

#### 小学低段（1-2年级）
- **数的认识**：万以内的数，整十数、整百数、整千数的认识；数位的含义（个位、十位、百位、千位）；数的大小比较
- **数的运算**：20以内加减法（口算）；100以内加减法（笔算）；表内乘法（乘法口诀）；简单的表内除法
- **常见的量**：认识人民币及简单计算；认识钟表（整时、半时）

#### 小学中段（3-4年级）
- **数的认识**：万以上的数（大数的读写）；小数的初步认识；分数的初步认识
- **数的运算**：三位数乘两位数；三位数除以一位数、两位数；小数加减法；混合运算与运算律（加法交换律、结合律，乘法交换律、结合律、分配律）
- **常见的量**：年月日、时分秒；千克与克、吨；千米与米

#### 小学高段（5-6年级）
- **数的认识**：因数与倍数；质数与合数；公因数与公倍数；小数和分数的深入理解；百分数；负数的初步认识
- **数的运算**：小数乘除法；分数四则运算；比和比例；四则混合运算
- **式与方程**：用字母表示数（简单代数式）；简单方程（如 ax+b=c）；正比例与反比例

#### 初中（7-9年级）
- **数与式**：有理数及其运算；实数；整式与分式；二次根式
- **方程与不等式**：一元一次方程；二元一次方程组；一元一次不等式与不等式组；一元二次方程
- **函数**：一次函数（正比例函数）；反比例函数；二次函数

---

### 主题二：图形与几何

#### 小学低段（1-2年级）
- **图形的认识**：认识长方形、正方形、三角形、平行四边形、圆等基本平面图形；认识长方体、正方体、圆柱、球等基本立体图形
- **图形与位置**：用上下、前后、左右描述位置关系
- **测量**：认识厘米、米；会用直尺测量物体的长度

#### 小学中段（3-4年级）
- **图形的认识**：平行与垂直；角的分类（锐角、直角、钝角、平角、周角）；三角形分类
- **测量**：面积的认识；长方形和正方形的面积公式；认识公顷和平方千米
- **图形的运动**：平移、旋转和轴对称的初步认识
- **图形与位置**：在方格纸上用数对表示位置

#### 小学高段（5-6年级）
- **图形的认识**：三角形的特性（内角和为180度）；平行四边形、梯形、圆的认识；长方体、正方体的认识
- **测量**：平行四边形、三角形、梯形的面积公式；圆的周长和面积公式；长方体和正方体的表面积和体积
- **图形的运动**：图形的放大与缩小；利用平移、旋转和轴对称进行简单的图案设计

#### 初中（7-9年级）
- **图形的性质**：三角形（全等三角形、等腰三角形、直角三角形）；四边形（平行四边形、矩形、菱形、正方形）；圆（圆的性质、与圆有关的位置关系、弧长和扇形面积）
- **图形的变化**：图形的平移、旋转、轴对称及其性质；相似图形（相似三角形）；位似
- **图形与坐标**：平面直角坐标系；坐标与图形的性质和变化
- **推理与证明**：几何证明的基本方法；三角形全等的判定；平行线的性质与判定

---

### 主题三：统计与概率

#### 小学低段（1-2年级）
- **数据的收集和整理**：用简单的方法收集和整理数据
- **数据的呈现**：用象形统计图和简单的统计表呈现数据

#### 小学中段（3-4年级）
- **数据的收集和整理**：简单的调查活动；记录和整理数据
- **数据的呈现**：认识条形统计图和简单的折线统计图
- **数据的分析**：读懂简单的统计图表中的数据信息；求平均数

#### 小学高段（5-6年级）
- **数据的收集和整理**：设计简单的调查问卷
- **数据的呈现**：复式条形统计图和复式折线统计图；扇形统计图
- **数据的分析**：中位数和众数；体会数据中蕴含的信息
- **随机现象**：体验事件发生的等可能性及游戏规则的公平性；能求简单随机事件发生的概率

#### 初中（7-9年级）
- **抽样与数据分析**：总体、个体、样本和样本容量；抽样方法
- **数据的集中趋势和离散程度**：加权平均数；中位数、众数；方差
- **事件的概率**：随机事件的概率；用列举法（列表、画树状图）求概率；用频率估计概率

---

### 主题四：综合与实践

#### 小学阶段
- **主题式学习**：选择贴近学生生活的主题（如"校园中的数学""购物中的数学"），综合运用数与代数、图形与几何、统计与概率等知识
- **项目式学习**：如"我们身体上的尺"（测量与估计）、"绘制校园平面图"（测量、比例、方位）
- **跨学科主题学习**：数学与科学、数学与艺术、数学与体育等跨学科整合

#### 初中阶段
- **课题学习**：选择具有一定挑战性的研究课题，经历发现和提出问题、分析和解决问题的全过程
- **数学建模活动**：从实际问题中抽象出数学问题，建立数学模型，求解并验证
- **数学探究活动**：对某些数学问题或规律进行探索，培养探究精神
- **跨学科主题学习**（必修）：至少10%的课时用于跨学科主题学习

## 四、学段目标概览

| 学段 | 年级 | 核心目标 |
|------|------|---------|
| 第一学段 | 1-2年级 | 积累数学活动经验，形成初步的数感、符号意识、空间观念、应用意识和推理意识 |
| 第二学段 | 3-4年级 | 进一步发展数感、量感、符号意识、运算能力、几何直观和应用意识 |
| 第三学段 | 5-6年级 | 形成初步的抽象思维，发展数据意识和模型意识，增强应用意识和创新意识 |
| 第四学段 | 7-9年级 | 发展抽象能力和推理能力，形成模型观念和数据观念，增强应用意识和创新意识 |

## 五、教学建议

### 总体教学建议
1. **注重数学与生活的联系**：选择贴近学生生活实际的素材，让学生感受数学来源于生活、应用于生活
2. **重视数学活动经验的积累**：让学生在观察、实验、猜想、验证、推理等活动中体验数学发现和创造的过程
3. **处理好过程与结果的关系**：既要重视结论的获得，更要重视结论获得的过程
4. **注重启发式教学**：调动学生学习的积极性，引导学生独立思考、主动探索、合作交流
5. **关注学生的个体差异**：因材施教，让不同的学生在数学上得到不同的发展

### 各领域教学建议

#### 数与代数
- 重视口算，加强估算，鼓励算法多样化
- 帮助学生理解算理，在理解基础上掌握算法
- 运算教学要与解决问题相结合
- 方程教学要突出等式的性质，渗透方程思想

#### 图形与几何
- 注重几何直观，帮助学生利用图形直观理解数学
- 重视实物操作和动手实践（剪、拼、摆、折、画）
- 图形的认识要从现实世界中的物体出发
- 空间观念的培养需要长期积累

#### 统计与概率
- 让学生经历收集数据、整理数据、描述数据、分析数据的全过程
- 重视统计的应用价值，联系实际生活
- 注意培养学生的数据分析观念和随机思维

#### 综合与实践
- 选择学生身边的、有意义的问题作为素材
- 注重培养学生发现和提出问题的能力
- 鼓励学生自主探索和合作交流

## 六、课标金句（常用引述）

> "数学课程要培养的学生核心素养，主要表现为'三会'：会用数学的眼光观察现实世界，会用数学的思维思考现实世界，会用数学的语言表达现实世界。"

> "核心素养具有整体性、一致性和阶段性。在不同学段，核心素养的表现具有阶段性特征。"

> "数学教学活动应注重启发式，引导学生独立思考、主动探索、合作交流，使学生在观察、实验、猜想、验证、推理与交流等数学活动中，逐步形成和发展核心素养。"

> "综合与实践以培养学生综合运用所学知识和方法解决实际问题的能力为目标。"

> "评价不仅要关注学生数学学习的结果，更要关注学生数学学习的过程；不仅要关注学生的学业水平，更要关注学生在数学活动中所表现出来的情感与态度。"

> "让学生在真实情境中发现问题和提出问题，利用观察、猜测、实验、计算、推理、验证、数据分析、直观想象等方法分析问题和解决问题。"

> "跨学科主题学习是综合与实践领域学习的拓展和延伸，旨在引导学生综合运用数学学科和跨学科的知识与方法解决问题。"

├── 统计与概率：扇形统计图、简单概率

├── 数与代数：有理数、实数、方程、不等式、函数
├── 图形与几何：三角形、四边形、圆、坐标几何、证明
├── 统计与概率：抽样、数据分析、概率计算
