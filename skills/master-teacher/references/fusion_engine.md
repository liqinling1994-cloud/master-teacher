# 融合引擎详细规则

> 本文档详细说明"名师方法论"与"新课标要求"如何在各教学设计环节中有机融合。
> 基于余文森"大单元教学设计四要素"框架。

---

## 一、融合框架：大单元教学设计四要素

```
大概念（Big Idea）    ← 主要由新课标提供
    ↓
大情境（Big Context）  ← 课标要求 + 名师经验共建
    ↓
大任务（Big Task）     ← 主要由名师方法论提供
    ↓
大问题（Big Question） ← 名师的问题链 + 课标的评价标准
```

### 1.1 大概念：课标主导

**来源**：2022版新课标中每个内容主题的"大概念"或"核心观念"

**操作规则**：
- 先从课标中提取本课所属内容主题的大概念
- 如果课标未直接给出大概念，从核心素养维度推导
- 大概念必须是**可理解的、可迁移的、有持久价值的**

**示例**：
```
课题：初中物理《浮力》
课标内容主题：物质的运动与相互作用
大概念：物体在流体中受到的浮力与其排开流体的重力相等（阿基米德原理）
素养对应：物理观念（力与运动）、科学思维（模型建构）
```

### 1.2 大情境：双方共建

**课标侧**：课标要求的"真实情境""生活情境""问题情境"
**名师侧**：名师创设情境的具体策略和经典案例

**操作规则**：
- 课标提供情境的"方向"（真实的、有意义的、与生活相关的）
- 名师提供情境的"具体设计"（用什么素材、怎么呈现、如何激发兴趣）
- 两者不能割裂，必须在同一个情境中同时体现

**示例**：
```
课标要求："创设真实的语言运用情境"
名师策略（窦桂梅·主题教学）：用"主题"统领情境——
  《落花生》的情境不是"种花生"，而是"什么是有用的人"
融合输出：以"校园辩论赛：外表重要还是内在重要？"为大情境，
  串联全课的阅读、讨论和写作活动
```

### 1.3 大任务：名师主导

**来源**：名师的课堂结构模型和核心学习任务设计

**操作规则**：
- 从名师卡片中提取TA对这类课题的典型任务设计
- 任务必须指向大概念，且能承载核心素养培育
- 如果名师有该课题的经典课例，优先复用其任务框架
- 如果无直接课例，迁移名师在同类课题中的任务设计逻辑

**示例**：
```
名师（华应龙·融错教育）设计的数学任务：
  不是"请计算浮力大小"
  而是"请预测这个物体会沉还是浮？"→ 让学生先犯错
  → 再通过实验验证 → 从错误中建构概念
```

### 1.4 大问题：双方协作

**名师侧**：名师的"关键问题链"（贯穿课堂的核心问题序列）
**课标侧**：学业质量标准（用来检验问题是否达到应有深度）

**操作规则**：
- 名师提供问题的"设计艺术"（怎么问、什么时机问、怎么追问）
- 课标提供问题的"深度校准"（问题能否引发达到相应学业质量水平的思考）
- 最终的问题链既有名师的灵巧，又有课标的深度

## 二、输出中的融合标注规范

### 2.1 标注符号体系

| 标注 | 含义 | 使用场景 |
|------|------|---------|
| 📐 | 课标依据 | 引用新课标原文或条目 |
| 💡 | 名师视角 | 名师对教学内容的独特理解 |
| 🎯 | 名师策略 | 名师的具体教学方法 |
| 🌟 | 亮点设计 | 名师策略与课标要求的创新融合 |
| ⚡ | 新课标适配 | 对名师旧课例的新课标视角重读 |

### 2.2 标注使用规则

```
1. 每份教学设计中，📐 和 💡/🎯 必须交替出现
   → 确保课标和名师两条线都贯穿始终

2. 教学目标部分：必须有 📐（课标依据）
   教学过程部分：必须有 🎯（名师策略）
   两者融合处：用 🌟 标注

3. 标注不能集中在某一个部分
   → 如果发现所有 📐 都在开头、所有 🎯 都在中间，说明融合不够
```

## 三、名师课例的"新课标重读"规则

### 3.1 为什么需要重读？

大部分名师经典课例形成于以下时期：
- 2001版课标（"三维目标"时代）
- 2011版课标修订版
- 2022版之前的教学实践

2022版课标的核心变化：
- 从"三维目标"转向"核心素养"
- 强调"大概念""大单元"
- 要求"真实情境""跨学科"
- 新增"学业质量标准"

### 3.2 重读操作步骤

```
步骤1：提取名师课例中的教学策略精华
  → 这些策略不过时，是跨时代的教学智慧

步骤2：识别课例中的"旧课标痕迹"
  → 如"知识与技能""过程与方法""情感态度价值观"的三维表述

步骤3：用新课标框架重新表述
  → 将三维目标转化为核心素养目标
  → 将教学过程用"大概念→大情境→大任务→大问题"重新组织

步骤4：补充新课标特有要求
  → 添加学业质量水平对标
  → 补充跨学科关联
  → 增加过程性评价设计
```

### 3.3 重读标注格式

```markdown
> ⚡ 新课标适配：{名师名}的《{课例名}》原设计目标为"知道...理解...感受..."
> （三维目标表述），现适配为核心素养目标：
> 【{素养维度}】{新表述}
```

## 四、多名师融合规则（名师碰撞模式）

### 4.1 触发条件

- 用户主动选择"名师碰撞"模式
- 课题本身适合从多个角度设计（如语文阅读课可以走"诗意"或"简约"路线）

### 4.2 融合方式

**方式A：对比呈现**（推荐）
```
同一课题，分别用名师A和名师B的风格设计两套方案
让老师看到不同路径的差异，自主选择
```

**方式B：取长补短**
```
名师A 负责"教什么"的选择
名师B 负责"怎么教"的策略
在一份方案中融合两者的优势
```

**方式C：问题驱动**
```
以一个核心问题为线索
名师A 会如何设计这个问题的探究路径？
名师B 会如何设计？
展示不同思路
```

### 4.3 冲突处理

当两位名师方法论明显矛盾时：
- 不要调和，而是清楚呈现差异
- 说明各自方法论的适用场景
- 标注"建议根据班级学情和个人风格选择"

## 五、动态名师检索机制（未收录名师的智能处理）

### 5.1 触发条件

当用户明确提到一个名师名字，但该名师不在当前知识库索引中时，自动触发。

**识别信号**：
- "我想用【XXX】老师的方法"
- "能参考【XXX】的教学设计吗"
- "【XXX】会怎么设计这节课"
- 其他明确指定未收录名师的表达

### 5.2 处理流程

```
Step 1: 识别未收录名师
  ↓ 检测到名师名字不在 references/index/ 和 references/masters/ 中
  
Step 2: 告知用户并征求同意
  ↓ "我发现【XXX】老师目前不在知识库中，我可以为你实时检索TA的教学方法。
     这可能需要1-2分钟，要继续吗？"
  
Step 3: 多源检索（用户同意后）
  ↓ a) 使用 WebSearch 搜索该名师的公开课视频、论文、专著
     b) 调用 AI 知识库中的相关信息
     c) 搜索教育期刊数据库（如"中国知网"相关内容）
  
Step 4: 生成临时名师卡片
  ↓ 按简化模板生成（包含：教学主张、核心策略、代表课例）
  
Step 5: 应用到当前教学设计
  ↓ 将临时卡片的策略融合到正在设计的教案中
  
Step 6: 标注信息可信度
  ↓ 明确标注"⚠️ 临时生成，基于公开资料"
  
Step 7: 询问是否永久收录
  ↓ "这是基于公开资料生成的临时卡片。如果你觉得有用，
     我可以将其完善后永久收录到skill中（★★级别）。需要吗？"
```

### 5.3 临时名师卡片格式（简化版）

```markdown

---

## 基本信息

- **姓名**：{名师全名}
- **学科**：{学科}
- **学段**：{学段}
- **教学主张**：{一句话核心理念}
- **信息来源**：{公开资料/网络检索/AI知识库}
- **可信度标注**：★（临时生成，未深度验证）

---

## 核心教学策略（2-3个）

### 策略1：{策略名称}

- **适用场景**：{什么课型适合}

|---------|-----------|------------|

如需更可靠的信息，请查阅该名师的原始著作或公开课实录。
```

### 5.4 信息可信度分级

| 等级 | 标识 | 说明 | 使用场景 |
|------|------|------|---------|
| ★★★ | 深度卡片 | 基于名师专著、公开课实录、论文，经过系统整理 | 已收录名师 |
| ★★ | 标准索引 | 基于名师公开教学主张和代表课例 | 索引中的名师 |
| ★ | 临时生成 | 基于网络检索和AI知识库，未深度验证 | 动态检索的名师 |
| 通用 | 无名师依据 | 通用教学策略，不归属具体名师 | 无名师匹配时 |

### 5.5 临时卡片的后续处理

**用户选择"不需要永久收录"**：
- 临时卡片仅用于本次对话
- 不保存到skill文件系统
- 下次再问同一名师，重新检索

**用户选择"需要永久收录"**：
- 将临时卡片升级为 ★★ 标准索引
- 保存到 `references/index/{学科}.md`
- 如果信息足够详细，进一步完善为 ★★★ 深度卡片
- 添加到 `learnings.md` 作为skill的自我进化记录

### 5.6 检索策略优先级

当动态检索名师时，按以下优先级查找信息：

```
优先级1（最高）：学术期刊论文
  → 搜索关键词："{名师名} 教学主张" "{名师名} 教学策略"
  
优先级2：公开课视频和文字实录
  → 搜索关键词："{名师名} 公开课" "{名师名} 优质课"
  
优先级3：出版专著
  → 搜索关键词："{名师名} 著作" "{名师名} 教学艺术"
  
优先级4：教育媒体报道
  → 搜索关键词："{名师名} 特级教师" "{名师名} 教学特色"
  
优先级5：AI知识库
  → 调用模型训练数据中关于该名师的信息
```

## 核心教学策略

### 策略1：对话式教学
- **定义**：教师不是知识的权威传递者，而是与学生平等对话的参与者
- **操作要点**：
  1. 鼓励学生质疑教师的观点
  2. 师生共同阅读同一本书，分享真实的阅读体验
  3. 课堂讨论中，教师不急于给出"标准答案"
- **适用场景**：整本书阅读、名著研讨、议题讨论课

### 策略2：真实写作
- **定义**：让学生写真话、抒真情，拒绝套话和虚假作文
- **操作要点**：
  1. 写作题目来自学生的真实生活和真实困惑
  2. 教师分享自己的写作（而非仅点评学生作文）
  3. 创建班级写作共同体，学生之间互相阅读和反馈
- **适用场景**：写作课、读后感、生活随笔

## 代表课例

| 课例名称 | 知识点/主题 | 核心设计亮点 |
|---------|-----------|------------|
| 《红楼梦》整本书共读 | 古典小说阅读 | 师生共读，教师不预设"正确理解"，鼓励学生提出不同观点 |
| 《背影》对话式教学 | 散文阅读 | 从"你觉得父亲翻月台买橘子是爱还是违规"引发真实讨论 |

## 应用到《背影》的建议

**传统教法 vs 李镇西式教法**：

传统：分析"父爱如山"的主题，让学生体会朱自清的情感
李镇西式：
  1. 抛出争议性问题："父亲翻月台的行为，你赞成吗？为什么？"
  2. 学生分组辩论（赞成方vs反对方）
  3. 教师分享自己的真实看法（可以和学生观点不同）
  4. 引导学生思考："爱是否可以超越规则？"
  5. 写作任务：写一封信给朱自清，说说你对他父亲的看法

### 5.8 防止滥用机制

为避免对动态检索功能的过度依赖，设置以下限制：

1. **单次对话限制**：每次对话最多动态检索3位未收录名师
2. **提示优先**：当用户询问名师时，优先推荐已收录的相似风格名师
3. **沉淀鼓励**：当同一名师被检索3次以上时，强烈建议永久收录

### 5.9 与现有流程的整合

```
用户输入 → 解析需求（学科/年级/课题/课型）
    ↓
检查是否提到名师
    ↓
名师在库中？
  Yes → 正常匹配流程（读取深度卡片或索引）
  No  → 触发动态检索机制
    ↓
生成临时卡片 → 应用到教学设计 → 询问是否永久收录
```
