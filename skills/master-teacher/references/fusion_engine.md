# 融合引擎详细规则

> 本文档详细说明"名师方法论"与"新课标要求"如何在各教学设计环节中有机融合。
> 基于余文森"大单元教学设计四要素"框架。

---

## 一、融合框架：大单元教学设计四要素

```
大概念（Big Idea）    ← 主要由新课标提供
    ↓
大情境（Big Context）  ← 课标要求 + 名师经验共建
    ↓
大任务（Big Task）     ← 主要由名师方法论提供
    ↓
大问题（Big Question） ← 名师的问题链 + 课标的评价标准
```

### 1.1 大概念：课标主导

**来源**：2022版新课标中每个内容主题的"大概念"或"核心观念"

**操作规则**：
- 先从课标中提取本课所属内容主题的大概念
- 如果课标未直接给出大概念，从核心素养维度推导
- 大概念必须是**可理解的、可迁移的、有持久价值的**

**示例**：
```
课题：初中物理《浮力》
课标内容主题：物质的运动与相互作用
大概念：物体在流体中受到的浮力与其排开流体的重力相等（阿基米德原理）
素养对应：物理观念（力与运动）、科学思维（模型建构）
```

### 1.2 大情境：双方共建

**课标侧**：课标要求的"真实情境""生活情境""问题情境"
**名师侧**：名师创设情境的具体策略和经典案例

**操作规则**：
- 课标提供情境的"方向"（真实的、有意义的、与生活相关的）
- 名师提供情境的"具体设计"（用什么素材、怎么呈现、如何激发兴趣）
- 两者不能割裂，必须在同一个情境中同时体现

**示例**：
```
课标要求："创设真实的语言运用情境"
名师策略（窦桂梅·主题教学）：用"主题"统领情境——
  《落花生》的情境不是"种花生"，而是"什么是有用的人"
融合输出：以"校园辩论赛：外表重要还是内在重要？"为大情境，
  串联全课的阅读、讨论和写作活动
```

### 1.3 大任务：名师主导

**来源**：名师的课堂结构模型和核心学习任务设计

**操作规则**：
- 从名师卡片中提取TA对这类课题的典型任务设计
- 任务必须指向大概念，且能承载核心素养培育
- 如果名师有该课题的经典课例，优先复用其任务框架
- 如果无直接课例，迁移名师在同类课题中的任务设计逻辑

**示例**：
```
名师（华应龙·融错教育）设计的数学任务：
  不是"请计算浮力大小"
  而是"请预测这个物体会沉还是浮？"→ 让学生先犯错
  → 再通过实验验证 → 从错误中建构概念
```

### 1.4 大问题：双方协作

**名师侧**：名师的"关键问题链"（贯穿课堂的核心问题序列）
**课标侧**：学业质量标准（用来检验问题是否达到应有深度）

**操作规则**：
- 名师提供问题的"设计艺术"（怎么问、什么时机问、怎么追问）
- 课标提供问题的"深度校准"（问题能否引发达到相应学业质量水平的思考）
- 最终的问题链既有名师的灵巧，又有课标的深度

## 二、输出中的融合标注规范

### 2.1 标注符号体系

| 标注 | 含义 | 使用场景 |
|------|------|---------|
| 📐 | 课标依据 | 引用新课标原文或条目 |
| 💡 | 名师视角 | 名师对教学内容的独特理解 |
| 🎯 | 名师策略 | 名师的具体教学方法 |
| 🌟 | 亮点设计 | 名师策略与课标要求的创新融合 |
| ⚡ | 新课标适配 | 对名师旧课例的新课标视角重读 |

### 2.2 标注使用规则

```
1. 每份教学设计中，📐 和 💡/🎯 必须交替出现
   → 确保课标和名师两条线都贯穿始终

2. 教学目标部分：必须有 📐（课标依据）
   教学过程部分：必须有 🎯（名师策略）
   两者融合处：用 🌟 标注

3. 标注不能集中在某一个部分
   → 如果发现所有 📐 都在开头、所有 🎯 都在中间，说明融合不够
```

## 三、名师课例的"新课标重读"规则

### 3.1 为什么需要重读？

大部分名师经典课例形成于以下时期：
- 2001版课标（"三维目标"时代）
- 2011版课标修订版
- 2022版之前的教学实践

2022版课标的核心变化：
- 从"三维目标"转向"核心素养"
- 强调"大概念""大单元"
- 要求"真实情境""跨学科"
- 新增"学业质量标准"

### 3.2 重读操作步骤

```
步骤1：提取名师课例中的教学策略精华
  → 这些策略不过时，是跨时代的教学智慧

步骤2：识别课例中的"旧课标痕迹"
  → 如"知识与技能""过程与方法""情感态度价值观"的三维表述

步骤3：用新课标框架重新表述
  → 将三维目标转化为核心素养目标
  → 将教学过程用"大概念→大情境→大任务→大问题"重新组织

步骤4：补充新课标特有要求
  → 添加学业质量水平对标
  → 补充跨学科关联
  → 增加过程性评价设计
```

### 3.3 重读标注格式

```markdown
> ⚡ 新课标适配：{名师名}的《{课例名}》原设计目标为"知道...理解...感受..."
> （三维目标表述），现适配为核心素养目标：
> 【{素养维度}】{新表述}
```

## 四、多名师融合规则（名师碰撞模式）

### 4.1 触发条件

- 用户主动选择"名师碰撞"模式
- 课题本身适合从多个角度设计（如语文阅读课可以走"诗意"或"简约"路线）

### 4.2 融合方式

**方式A：对比呈现**（推荐）
```
同一课题，分别用名师A和名师B的风格设计两套方案
让老师看到不同路径的差异，自主选择
```

**方式B：取长补短**
```
名师A 负责"教什么"的选择
名师B 负责"怎么教"的策略
在一份方案中融合两者的优势
```

**方式C：问题驱动**
```
以一个核心问题为线索
名师A 会如何设计这个问题的探究路径？
名师B 会如何设计？
展示不同思路
```

### 4.3 冲突处理

当两位名师方法论明显矛盾时：
- 不要调和，而是清楚呈现差异
- 说明各自方法论的适用场景
- 标注"建议根据班级学情和个人风格选择"
