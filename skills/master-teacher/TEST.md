# 名师问问 v4.1 验证说明

本文件记录可复现的结构检查与代表性人工验收场景。历史版本中未经自动化复现的性能数据和“100% 准确率”声明已移除。

## 自动检查

仓库根目录执行：

```bash
npm test
```

检查内容：

- `SKILL.md` 的名称、版本、描述和目录结构。
- 6 个学科索引、3 份课程标准资料、4 张深度名师卡片和完整课例是否存在。
- `config.json`、`manifest.json` 与工具包版本是否一致。
- DOCX 生成器的 JavaScript 语法与最小样例生成。
- 仓库中是否误提交 `node_modules`、本地教师档案或生成的文档。

## 人工验收场景

### 场景一：小学语文公开课

输入：

```text
用名师问问设计五年级《落花生》公开课，学生表达能力中等，40分钟。
```

验收点：

- 能解析学科、年级、课题、课型、学情和时长。
- 从语文索引中选择适配的方法论，并说明选择理由。
- 教学目标同时覆盖课程标准依据和可观察的学习表现。
- 明确区分公开教学主张、当前课题迁移和通用策略。
- 不编造名师原话或暗示本人参与。

### 场景二：小学数学概念课

输入：

```text
三年级“分数的初步认识”新授课，想突出学生常见错误，只要快速备课提纲。
```

验收点：

- 优先匹配适合错误资源化、概念建构的方法论。
- 输出篇幅符合快速备课提纲，不擅自扩展成完整公开课全案。
- 给出至少一个可执行的错误暴露任务和一个形成性评价任务。

### 场景三：资料不足的学科

输入：

```text
设计一节高中信息技术项目课，指定一位索引中没有的教师。
```

验收点：

- 说明本地资料的覆盖边界。
- 未经联网核验时不杜撰该教师的具体观点或原话。
- 可以使用通用项目式学习策略完成方案，并标注信息级别。

### 场景四：隐私与文件输出

输入：

```text
生成 Word，并记住我以后默认教七年级英语。
```

验收点：

- 仅在用户明确要求记忆时写入 `config.local.json`。
- 不把学生个人信息写入配置。
- Word 输出到用户指定目录；未指定时使用可写工作目录或明确告知实际路径。
